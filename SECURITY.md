# Security policy

Prosewire is under private pre-release development and does not yet publish supported-version guarantees.

Report suspected vulnerabilities privately to the repository maintainers. Use GitHub's private vulnerability reporting or a private security advisory when available; do not include exploit details in a public issue. Include affected versions or commits, reproduction steps, impact, and any suggested mitigation.

Maintainers will acknowledge a report, validate it, coordinate a fix, and disclose it with the eventual release when appropriate.
