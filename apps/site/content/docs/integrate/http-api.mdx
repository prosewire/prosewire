## Public JSON

```http
GET /api/public/:blog/posts
GET /api/public/:blog/posts/:slug
```

The list endpoint accepts `page`, `pageSize` (maximum 100), `search`, and `category`. Its response includes `pagination.page`, `pagination.pageSize`, and `pagination.hasMore`, alongside author and category relationships. The legacy `limit` query parameter remains an alias for `pageSize`.

## Rendered HTML

```http
GET /api/rendered/:blog
GET /api/rendered/:blog/:slug
```

Rendered routes return sanitized, semantic HTML. They are useful when the host wants server-rendered content without adopting Prosewire’s JavaScript loader.

## Private operations

Authenticated publishing operations use scoped API keys and the shared Effect HttpApi/OpenAPI contract. Mutations create audit records, and destructive agent operations carry explicit risk metadata.
